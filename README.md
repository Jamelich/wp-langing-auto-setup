WordPress Auto-Setup Script
Версия: 3.1-ALL-IN-ONE
Репозиторий: https://github.com/Jamelich/wp-langing-auto-setup

Автоматический скрипт для быстрого развёртывания чистого WordPress, установки необходимых плагинов и темы прямо на хостинг.

ЧТО ДЕЛАЕТ ЭТОТ СКРИПТ

Одной командой подготавливает полностью рабочую среду для нового сайта на WordPress:

1. Устанавливает свежий WordPress - скачивает и распаковывает последнюю стабильную версию с wordpress.org.
2. Устанавливает набор плагинов - предустановленный список часто используемых плагинов.
3. Устанавливает тему esalanding - загружает вашу тему с GitHub.
4. Устанавливает Carbon Fields - автоматически через локальный Composer (без прав на сервере).

БЫСТРЫЙ СТАРТ

Внимание! Скрипт полностью очищает текущую папку перед установкой. Запускайте в пустой или предназначенной для этого папке.

Чтобы установить WordPress с плагинами и темой, выполните команду в терминале:

rm -f setup.sh && wget -q https://raw.githubusercontent.com/Jamelich/wp-langing-auto-setup/main/setup.sh?$(date +%s) -O setup.sh && bash setup.sh

ТРЕБОВАНИЯ

- PHP 7.4 или выше (рекомендуется 8.0-8.3)
- Доступ в интернет (для скачивания WordPress, плагинов и зависимостей)
- Bash (стандартная оболочка на большинстве хостингов)

Важно для хостинга Beget:
На Beget версия PHP в SSH может отличаться от версии для веб-сервера. Скрипт автоматически найдёт PHP 8.3 в /usr/local/php/cgi/8.3/bin/php. Если у вас другая версия, скрипт подхватит 8.2, 8.1 или системную.

НАСТРОЙКА ПОД СВОИ НУЖДЫ

Чтобы изменить список плагинов, отредактируйте массив PLUGINS в файле setup.sh:

PLUGINS=(
    "wordpress-seo"
    "contact-form-7"
    "classic-editor"
    "classic-widgets"
    "cyr2lat"
    "cookie-law-info"
    "yandex-metrica"
)

Чтобы сменить тему, замените ссылку на архив темы в блоке "УСТАНОВКА ТЕМЫ":

wget -q "https://github.com/ВАШ_ЛОГИН/ВАША_ТЕМА/archive/refs/heads/main.zip" -O theme.zip

УСТРАНЕНИЕ НЕПОЛАДОК

Ошибка "Версия PHP слишком старая":
Скрипт требует PHP 7.4 или выше. Если на сервере стоит старая версия:
1. Зайдите в панель управления хостингом
2. Найдите настройки PHP для вашего сайта
3. Установите версию PHP 8.3 (рекомендуется) или 7.4
4. Сохраните изменения и подождите 2-3 минуты
5. Проверьте версию в SSH: php -v | head -1

Ошибка 500 при запуске:
Если терминал выдаёт 500, возможно:
- Вы работаете через WinSCP, а SSH доступ выключен
- Включите SSH в панели управления хостингом (например, на Beget)
- Используйте веб-терминал в панели хостинга

Ошибка прав доступа при установке Composer:
Скрипт устанавливает Composer локально в папку темы, поэтому права на /usr/local/bin не требуются.

Ошибка "No composer.json present":
Скрипт автоматически создаёт composer.json и устанавливает Carbon Fields через локальный Composer.
